# Kings Squire Project

## Overview
This project is a document search engine built in Python. It allows users to load documents and search for keywords using different search methods.

## Features
- Load documents (text/PDF if you added it)
- Search for keywords
- Compare search speeds (linear vs indexed)
- Command-line interface

## How to Run
1. Install Python
2. Navigate to project folder
3. Run:
   python main.py

## FILES
- main.py → main program
- search_engine.py → search logic
